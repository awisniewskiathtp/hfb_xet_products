XET Products

XML product import and export over SFTP, built on XET Base

Overview

The module imports products from an XML file fetched over SFTP and periodically exports products to XML, generated from an XET template, to configured recipients over SFTP.

Every import or export is one record in Communication logs (communication.log) that goes through stages, can be resumed and keeps its counters, file and history. XET Base (hfb_xmlmap_exporter) is used as is: the module adds a provider type and its own run logic.

Features

Import
  • File taken from an SFTP directory by name pattern; with an archive directory the oldest file is processed first, without it the newest one; a file is never skipped
  • Streaming XML parser, staging lines with per-line state and error message
  • Products matched by SKU + EAN; only changed fields are written, new products are created
  • A failing line does not stop the run (savepoint per line)
  • Main photo downloaded into the product image, only when its URL changes
  • Remote file moved to the archive or error directory
Export
  • One channel per recipient: own SFTP account, directory, file name and XET template
  • Full or incremental export (changes since the last accepted run)
  • XML generated by the XET template engine, cleaned (no namespaces, CDATA where configured)
  • Optional XSD validation
  • Atomic upload: temporary .part file, then rename and size check
Run control
  • One worker cron with a time budget; imports are processed before exports
  • At most one active run per channel (database unique index)
  • Interrupted stages are detected and retried; retries with delay, then error
  • Filters "XET Products", result and stage in Communication logs
Product data
  • PIM fields on the product form (tab PIM): identification, producer, prices, flags, codes and certificates, packaging and carton data, descriptions
  • Media links (tab Media) typed by an editable dictionary, so new link types need no code

How it works

DirectionStagesFinal result
Importfetch → parse → apply → images → finalizeFinished, Finished with line errors, Nothing to process, Error
Exportselect → generate → send → finalizeFinished, Nothing to process, Error
  1. Initialising crons create a run for each active channel without a run in progress (import by default every hour, export every day).
  2. The worker cron (every minute) executes the stages of pending runs within its time budget.
  3. Uruchom przebieg teraz (run now) on a channel creates a run and processes it immediately.

Configuration

  1. Server – install the Python library paramiko.
  2. Channels – XET Provider → Konfiguracja → Konfiguracja Dostawców → Provider XET Products: one import channel and one export channel per recipient; set SFTP access, directories and options.
  3. Connection – use Test połączenia (connection test); optionally copy the reported host key fingerprint into the channel.
  4. Schedule – activate the three XET Products scheduled actions and set their intervals.
  5. Media types – XET Provider → Konfiguracja → XET Products → Typy mediów.
