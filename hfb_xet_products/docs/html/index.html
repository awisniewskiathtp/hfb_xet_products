Przegląd modułu

Import i eksport produktów XML przez SFTP na bazie XET Base (Odoo 20).

Przeznaczenie

Moduł importuje produkty z pliku XML pobieranego przez SFTP i cyklicznie eksportuje produkty do XML według szablonu XET, z wysyłką przez SFTP do wskazanych odbiorców. Korzysta z mechanizmów XET Base (communication.provider, communication.log, xml.export.template) bez ich modyfikacji. Wzorcem przebiegów i wyłączności był moduł hfb_apds (projekt ALIAS), z jednym workerem zamiast wielu.
